## 🛠️ Roadmap & Topics Covered

### 1. Introduction to Java

* Java Virtual Machine (JVM), JDK, and JRE architecture
* Variables, Data Types, and Operators
* Control Flow Statements (`if-else`, `switch-case`, loops)

### 2. Core Java (Basic)

* Arrays (1D and Multi-dimensional)
* String Handling (String, StringBuilder, StringBuffer)
* Methods and Memory Management (Stack vs Heap)

### 3. Object-Oriented Programming (OOPs)

* Classes and Objects
* The Four Pillars: **Inheritance, Polymorphism, Encapsulation, and Abstraction**
* Interfaces and Abstract Classes
* Constructors and `this`/`super` keywords

### 4. Intermediate Java

* **Exception Handling:** `try-catch-finally`, throw vs throws, custom exceptions
* **Java Collections Framework:** List, Set, Map, Queue, and Iterator
* **Generics:** Creating type-safe classes and methods
* **File I/O:** Reading and writing files using Streams

### 5. Advanced Java

* **Multithreading & Concurrency:** Thread life cycle, Synchronization, Executor Framework
* **Java 8+ Features:** Lambda Expressions, Stream API, Functional Interfaces, and `Optional` class
* **Database Connectivity:** JDBC basics and interacting with SQL databases
* **Design Patterns:** Creational, Structural, and Behavioral patterns in Java

## 🚀 How to Run the Code

### Prerequisites

Make sure you have the Java Development Kit (JDK 8 or higher) installed on your system. You can check your version by running:

```bash
java -version
```
